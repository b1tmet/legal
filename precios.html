Preguntas frecuentes

¿Qué cuenta como petición?

Cada llamada a /v1/forecast/point, /v1/domains o /v1/domains/{dominio}/runs que responde con datos o con coordenadas fuera del dominio. /v1/usage y /v1/status no cuentan.

¿Cuándo se reinician las cuotas?

La cuota diaria, a las 00:00 UTC. La de por minuto, al empezar cada minuto.

¿Qué pasa si supero el límite?

La API responde con el código 429 y la cabecera Retry-After, que indica cuántos segundos esperar. No se cobra nada extra.

¿Con qué frecuencia se actualiza el pronóstico?

El modelo se ejecuta cuatro veces al día (00, 06, 12 y 18 UTC). Cada respuesta indica la corrida usada en run_init.

¿Puedo usarla desde un navegador?

Sí, la API admite peticiones desde cualquier origen. Ten en cuenta que una clave incluida en una web es visible para cualquiera: si se filtra, la revocamos y te damos otra.

¿Puedo usar el plan Free en un producto comercial?

No. Free es para evaluación. Para uso comercial necesitas Starter o un plan superior.

¿Cómo contrato un plan?

Pulsa el botón del plan: el pago se procesa con Stripe y, al terminar, verás tu clave en pantalla. Para el plan Free, solicita la clave con tu correo y te enviaremos un enlace para verla. Para Enterprise, escríbenos.

¿Puedo cancelar?

Sí. La suscripción es mensual y puedes cancelarla cuando quieras; tu clave sigue activa hasta el final del periodo pagado. Puedes hacerlo desde el portal de cliente (enlace en el correo de bienvenida).

Los pronósticos son orientativos y no sustituyen los avisos oficiales de los servicios meteorológicos nacionales. El uso de la API está sujeto a los Términos de la API.

FAQ

What counts as a request?

Every call to /v1/forecast/point, /v1/domains or /v1/domains/{domain}/runs that returns data or reports coordinates outside the domain. /v1/usage and /v1/status are not counted.

When do quotas reset?

The daily quota at 00:00 UTC. The per-minute limit at the start of each minute.

What happens if I exceed the limit?

The API returns status 429 with a Retry-After header telling you how many seconds to wait. There are no extra charges.

How often is the forecast updated?

The model runs four times a day (00, 06, 12 and 18 UTC). Each response shows the run used in run_init.

Can I use it from a browser?

Yes, the API accepts requests from any origin. Keep in mind that a key embedded in a website is visible to anyone: if it leaks, we revoke it and issue a new one.

Can I use the Free plan in a commercial product?

No. Free is for evaluation. Commercial use requires Starter or a higher plan.

How do I subscribe?

Click the plan's button: payment is processed by Stripe and, when it's done, your key is shown on screen. For the Free plan, request a key with your email and we'll send you a link to see it. For Enterprise, contact us.

Can I cancel?

Yes. The subscription is monthly and you can cancel at any time; your key stays active until the end of the paid period. You can do it from the customer portal (link in the welcome email).

Forecasts are for guidance only and do not replace official warnings from national weather services. Use of the API is subject to the API Terms.

Alle abonnementen bevatten dezelfde variabelen, elke 3 uur: temperatuur en relatieve luchtvochtigheid op 2 m, luchtdruk aan het oppervlak en op zeeniveau, windsnelheid en windrichting op 10 m, neerslag over 3 uur en gevoelstemperatuur. In metrische of imperiale eenheden.

Veelgestelde vragen

Wat telt als verzoek?

Elke aanroep van /v1/forecast/point, /v1/domains of /v1/domains/{domein}/runs die gegevens teruggeeft of coördinaten buiten het domein meldt. /v1/usage en /v1/status tellen niet mee.

Wanneer worden de quota gereset?

Het dagquotum om 00:00 UTC. De limiet per minuut aan het begin van elke minuut.

Wat gebeurt er als ik de limiet overschrijd?

De API antwoordt met code 429 en de header Retry-After, die aangeeft hoeveel seconden je moet wachten. Er worden geen extra kosten in rekening gebracht.

Hoe vaak wordt de voorspelling bijgewerkt?

Het model draait vier keer per dag (00, 06, 12 en 18 UTC). Elk antwoord vermeldt de gebruikte modelrun in run_init.

Kan ik de API vanuit een browser gebruiken?

Ja, de API accepteert verzoeken van elke herkomst. Houd er rekening mee dat een sleutel in een website voor iedereen zichtbaar is: als hij uitlekt, trekken we hem in en krijg je een nieuwe.

Mag ik het Free-abonnement in een commercieel product gebruiken?

Nee. Free is bedoeld voor evaluatie. Voor commercieel gebruik heb je Starter of een hoger abonnement nodig.

Hoe neem ik een abonnement?

Klik op de knop van het abonnement: de betaling verloopt via Stripe en daarna zie je je sleutel op het scherm. Voor het Free-abonnement vraag je een sleutel aan met je e-mailadres en we sturen je een link om hem te bekijken. Voor Enterprise neem je contact met ons op.

Kan ik opzeggen?

Ja. Het abonnement is maandelijks en je kunt het altijd opzeggen; je sleutel blijft actief tot het einde van de betaalde periode. Dat kan via het klantenportaal (link in de welkomstmail).
