Cada recuadro es un dominio del modelo. Pasa el cursor por un dominio de la lista (o tócalo) para resaltarlo.

Each box is a model domain. Hover over a domain in the list (or tap it) to highlight it.

Cada retângulo é um domínio do modelo. Passe o cursor sobre um domínio da lista (ou toque nele) para destacá-lo.

Chaque cadre est un domaine du modèle. Survolez un domaine de la liste (ou touchez-le) pour le mettre en évidence.

Ogni riquadro è un dominio del modello. Passa il cursore su un dominio dell'elenco (o toccalo) per evidenziarlo.

Elk kader is een modeldomein. Beweeg over een domein in de lijst (of tik erop) om het te markeren.

    Los recuadros son los límites en latitud y longitud de cada malla. El plan Free usa las mallas d01; los planes de pago, todas.

    Boxes show the latitude and longitude bounds of each grid. The Free plan uses the d01 grids; paid plans use all of them.

    Os retângulos mostram os limites de latitude e longitude de cada grade. O plano Free usa as grades d01; os planos pagos, todas.

    Les cadres indiquent les limites en latitude et longitude de chaque grille. L'offre Free utilise les grilles d01 ; les offres payantes, toutes.

    I riquadri indicano i limiti in latitudine e longitudine di ciascuna griglia. Il piano Free usa le griglie d01; i piani a pagamento, tutte.

    De kaders tonen de breedte- en lengtegrenzen van elk rooster. Het Free-abonnement gebruikt de d01-roosters; betaalde abonnementen alle roosters.

    Una sola llamada devuelve el pronóstico de un punto. La API elige la malla más detallada que lo cubre.

    A single call returns the forecast for a point. The API picks the most detailed grid that covers it.

    Uma única chamada retorna a previsão de um ponto. A API escolhe a grade mais detalhada que o cobre.

    Un seul appel renvoie la prévision d'un point. L'API choisit la grille la plus détaillée qui le couvre.

    Una sola chiamata restituisce la previsione di un punto. L'API sceglie la griglia più dettagliata che lo copre.

    Eén aanroep geeft de voorspelling voor een locatie. De API kiest het meest gedetailleerde rooster dat die locatie dekt.

    curl "https://thredds.b1tmet.com/v1/forecast/point?lat=23.13&lon=-82.38&hours=24" \
  -H "Authorization: Bearer $B1TMET_KEY"
    const res = await fetch(
  "https://thredds.b1tmet.com/v1/forecast/point?lat=23.13&lon=-82.38&hours=24",
  { headers: { Authorization: `Bearer ${B1TMET_KEY}` } }
);
const { model, data } = await res.json();
console.log(model.domain, data[0].temperature_2m);
    import os, requests

r = requests.get(
    "https://thredds.b1tmet.com/v1/forecast/point",
    params={"lat": 23.13, "lon": -82.38, "hours": 24},
    headers={"Authorization": f"Bearer {os.environ['B1TMET_KEY']}"},
    timeout=60,
)
print(r.json()["data"][0]["temperature_2m"])
